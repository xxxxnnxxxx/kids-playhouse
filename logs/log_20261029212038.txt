====================================================================
根据docs/童趣游戏屋 · 儿童游戏网站.html下的网站模板文件，创建一个网站，基于golang+gin框架，

二、我对需求的理解
====================================================================
1. 以 docs/童趣游戏屋 · 儿童游戏网站.html 为视觉模板，搭建一个真实可用的儿童游戏网站"童趣游戏屋"。
2. 后端指定使用 Golang + Gin 框架。
3. 网站必须支持两类游戏在浏览器中直接在线玩：
   - HTML5 游戏（纯前端 JS/Canvas 实现）；
   - Python 游戏（在浏览器里运行 Python 代码，无需本地安装 Python）。
4. 技术栈由我给出建议并说明理由，核心决策点：是否前后端分离；前端 HTML 用 Node 工具链（如 Vite）编译构建后交给后端应用（托管静态资源）。

====================================================================
三、技术方案（待确认）
====================================================================
【总体架构：前后端分离 + 单体部署（推荐）】
- 前端：Node + Vite + TypeScript（原生 DOM，不引入 Vue/React 重框架），
  `npm run build` 产出静态文件到 web/dist。
- 后端：Go + Gin，职责：
  1) REST API（如 GET /api/v1/games 返回游戏列表元数据，卡片内容从接口渲染，便于后续增删游戏）；
  2) 托管前端编译产物 web/dist（SPA 静态文件 + 兜底路由）；
  3) 托管 HTML5 游戏静态目录与 Python 游戏资源。
- 开发期：Vite dev server（5173 端口）proxy /api 到 Gin（8080 端口），前后端并行开发；
  生产期：只需运行一个 Go 服务，访问单一域名即可，无跨域问题。
- 理由：架构上是分离的（前端独立编译、接口清晰），部署上是一体的（一个二进制 + 静态文件），
  兼顾工程性与简单性；满足"html 用 node 编译后应用"的要求。

【HTML5 游戏运行方式】
- 每款游戏一个独立目录 games/html5/<游戏id>/index.html，自包含 JS/Canvas；
- 游戏页通过 iframe 嵌入站点播放页，与主站样式隔离、互不干扰。

【Python 游戏运行方式 —— 两个候选，需用户选择】
方案 A（推荐）：Pyodide（浏览器端 CPython/WebAssembly 运行时）
- Python 游戏以 .py 源码形式存放，前端加载 Pyodide 后在浏览器内直接执行；
- 站点提供一个轻量兼容层（Python 模块）：控制台输入输出重定向到页面终端、
  turtle 风格画图与简易画布/键盘 API（用 Python 实现贪吃蛇、跳跃小鸟等）；
- 优点：无需为每款游戏跑 Python 构建链，部署就是"Go 服务 + 静态文件"；
  孩子还能在线查看/修改 Python 源码立即运行，契合"边玩边学编程"定位；
- 缺点：不是真正的 pygame 库，游戏需按站点提供的 API 编写。
方案 B：pygbag（真正的 pygame 编译为 WebAssembly）
- 每款 pygame 游戏需在本机用 Python 工具链（pygbag）预先编译成 wasm 静态包，Gin 只负责托管；
- 优点：真 pygame API；缺点：每款游戏都要跑构建、包体大（数十 MB 级），
  且无法在线改代码，开发迭代成本高。

五、对模板的影响说明（重要）
====================================================================
1. 原模板是 1440px 固定宽度、绝对定位的设计稿（导出画板），不能直接当网页用；
   实施时会保留其视觉风格（配色、字体层级、卡片样式、各区块内容），
   但布局改为常规文档流 + 响应式（自适应屏幕宽度），否则在手机/不同分辨率下无法正常浏览。
2. 模板中的静态卡片文案（游戏名、年龄、难度）会迁移为接口数据驱动的游戏卡片；
   暂未实现的游戏卡片标记"即将上线"，不会删除任何模板既有的区块
   （顶栏、Hero、两个游戏区、统计条、CTA、页脚全部保留）。
3. 模板引用 Google Fonts，国内网络可能加载失败，将保留引用并配好系统字体回退，不影响功能。
